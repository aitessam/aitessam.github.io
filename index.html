MedRAG

Grounded answers to patient questions, by text or voice, from the patient's own record.

Hybrid RAGRerankingWhisperOllama
Open source · 100+ tests, CI, Docker
Problem
Generic chatbots guess. Patients need answers from their own record, and diagnosis requests must be refused safely.
Approach
LLM router (patient, general, unsafe), one fact per chunk, BM25 + FAISS hybrid search, cross-encoder reranking, privacy-safe audit logs.
Result
The right fact reaches the LLM for 95% of answerable questions. Evaluation exposed a gate that would have refused 61% of them, so I redesigned it.
