Healthcare AI · RAG · Agents

MedRAG: grounded answers from the patient's own record

A Flask API that answers health questions by text or voice, routing each question and answering only from retrieved facts.

ProblemPatients ask about their own record; a generic chatbot will guess. Diagnosis or treatment requests must be refused safely.
ApproachLLM router (patient, general, unsafe), one fact per chunk, BM25 + FAISS hybrid search, cross-encoder reranking, Whisper voice in and out, privacy-safe audit logs.
ResultRight fact reaches the LLM for 95% of answerable questions. Evaluation exposed a gate that would have refused 61% of them, so I redesigned it. 100+ tests, CI, Docker.

Arabic NLP · RAG

Arabic document RAG with page citations

Upload Arabic reports and ask in Arabic or English; every claim cites the document and page.

ProblemEnglish RAG pipelines break on Arabic: reversed PDF text, letter variants, attached prefixes.
ApproachRight-to-left block ordering, Arabic normalisation, sentence-aware chunking, hybrid BM25 + e5 retrieval.
ResultCross-lingual answers with page-level citations, and an explicit "not found" instead of guessing.
